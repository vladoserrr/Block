# BLOCK — Telegram Mini App

Мобильный интерфейс обменника ByteCoin для Telegram.

## Запуск
```bash
npm install
npm run dev
``

## Сборка
```bash
npm run build
``

## Telegram
Разместите папку `dist` на HTTPS-хостинге и укажите полученный адрес как Web App URL кнопки Telegram-бота. SDK Telegram Web Apps уже подключён в `index.html`.

## Важно: сервер обмена ещё не подключён
Сейчас в репозитории реализован интерфейс и предварительный расчёт:
- Покупка BC: 10 ₽ за 1 000 000 BC.
- Продажа BC: 6 ₽ за 1 000 000 BC.

Подтверждение формы не создаёт реальную сделку, не переводит BC и не меняет резервы или статистику. Для реального обмена необходим сервер, база данных, проверка Telegram initData, обработка заявок оператором и учёт резервов. Нельзя доверять суммам и балансу, переданным только из браузера.
